# عالجمر

مطعم خليجي — مشاوي وعيش. **يُفتتح قريباً.** موقع عرض أوّلي.

> **نسخة عرض، لا نسخة نهائيّة.** الحقول التي لم تُعطَ لنا بعد (المدينة،
> العنوان، الهاتف، تاريخ الافتتاح، الأسعار) مكتوبةٌ في الموقع **أنها لم
> تُحسَم** — ولم تُملأ بأرقام مُلفَّقة.

## التشغيل

```bash
# افتح الصفحة
open index.html          # أو انشرها على GitHub Pages

# شغّل كل الحوارس قبل أي دفعة
bash verify.sh
```

## ما في الموقع

صفحة واحدة، عربيّة RTL، اثنا عشر قسماً:

| القسم | المحتوى |
|---|---|
| الواجهة | الاسم · سرير جمر متوهّج · «يُفتتح قريباً» |
| الفكرة | الجمر هو الطاهي |
| الجمر | المجمر المكشوف في الصالة + رسم المَنقل |
| العيش | **تسعة أنواع أرزّ خليجي**: مجبوس · كبسة · مضغوط · مظبي · مندي · بخاري · معمّر · صيادية · عيش وكباب |
| الكباب | ستّة من المشاوي |
| المائدة | مُختار من القائمة في أربعة أعمدة، **بلا أسعار** (لم تُقرَّر) |
| المجلس | أربعة أعمدة لتجربة الخمس نجوم + رسم الدلّة |
| التواصل | حقول الافتتاح، معلَنة النقص |

## الخطّ — رقعةُ عارف وأميري، مستضافان محلياً

| | |
|---|---|
| العرض (الاسم والعناوين) | **Aref Ruqaa** — رقعة كلاسيكيّة · اختيار المالك |
| النصّ | **Amiri** — نسخ، إحياءً لحرف مطبعة بولاق · ومن نفس بيت رقعة عارف |

وكلاهما في `assets/fonts/` بـ`@font-face` داخل `tokens.css`، ومعهما نصّ
رخصة **SIL OFL 1.1** كما تشترط — فلا يُحذَف `OFL-*.txt`.

> **لا طلبَ لطرفٍ ثالثٍ في الصفحة إطلاقاً.** لا يُرسَل زائرُك إلى Google،
> ولا تنكسر الكتابةُ إن حُجب، والخطُّ من خادمِك. ووزنُه **677 ك.ب**
> يُقال ولا يُكتَم — ويُخفَّض إلى نحو النصف بتحويلٍ إلى `woff2`، وهو
> **بندٌ مفتوحٌ لا منجَز** (لا أداةَ تحويلٍ في صندوق البناء).

تُستعمل **أسطحاً خلفيّةً** تحت حجابٍ فحميٍّ يُبقي النصَّ مقروءاً، لا
بطاقاتٍ معروضة. وحكمُ الحقوق على كل ملفّ وصل في `docs/RIGHTS-NOTICE-2.md`،
**وثلاثةٌ من الدفعة لم تدخل ولا تدخل**: صورةُ منتجِ سجّادة · قالبُ بطاقةٍ
فارغة · مصغَّرةُ Pinterest.

> ⚠️ **سطرٌ قديمٌ صُحِّح:** كان هنا `Reem Kufi` و`IBM Plex Sans Arabic`،
> وكلاهما **هندسيُّ البنية** فحُذفا بقرار المالك. والخطُّ الآن رقعةُ
> عارف وأميري (انظر أعلاه).

**لا رسوم هنديّة** — قرار المالك، مُنفَّذ على القراءتين:
- **الأرقام** تُكتب `0123456789` دائماً، و`font-feature-settings: "locl" 0`
  يمنع الخطّ من استبدالها تلقائياً عند `lang="ar"`. ويحرسها `check_numerals.py`.
- **الزخرفة** خليجيّة أصيلة: هندسة السدو · النقش الجبسي النجدي · المشربيّة.
  لا بيزلي ولا أقواس مغوليّة ولا ماندالا.

## الحقوق — نظيفة بالكامل

**كل رسم في هذا الموقع مرسوم خصّيصاً له**: عشرون رمزاً هندسيّاً ولوحتان
متجهيّتان (المَنقل · الدلّة)، والنقشات مولَّدة بـCSS حسابياً.

> لا صورة مُلتقطة · لا أيقونة مستوردة · لا عمل فنّي لأحد · لا موسيقى · لا
> صورة شخصٍ حقيقي · لا علامة تجاريّة لغيرنا.

وهذا قرار مقصود لا نتيجة نقص: في مشروع سابق للمالك رُصدت أربع مشكلات حقوق
في موادّ جاهزة. وأي أصل يُرسله المالك لاحقاً (شعار، صور أطباق، موسيقى)
**يُفحَص قبل أن يدخل** بحثاً عن علامات مائيّة وشعارات غريبة وصور أشخاص
وعلامات تجاريّة.

## البنية


(و`sadu.css` حُذف مع كل ما هو هندسي — كان مذكوراً هنا وهو غير موجود.)

## ⚠️ لقطات الشاشة العربيّة لا يصحّ الحكم بها

الصندوق الذي بُني فيه هذا الموقع **بلا خطوط عربيّة** (`fc-list` = عشرة خطوط،
صفر عربي)، فالعربي يُرسَم مربّعات فارغة. ومنه:

- `docs/preview/latin-type.png` — صفحة نصّ **لاتيني**، وهي الأساس الوحيد
  الصحيح للحكم على التبايُن والمقاسات والتخطيط
- ✅ **وقد سقط هذا القيد جزئياً:** الخطّ صار مستضافاً محلياً، فلقطةُ
  العربيِّ صحيحةٌ وقابلةٌ للحكم — `docs/preview/site-hero-v3.png`.
  ويبقى القيدُ قائماً لأيِّ نصٍّ بخطٍّ من CDN

## ما ينتظر المالك

1. **المدينة والموقع** · **تاريخ الافتتاح** · **الهاتف** · **حسابات التواصل**
2. **الشعار** إن وُجد — وإلّا فالاسم مكتوب برقعةِ عارف، وما رُفع
   باسم `logo` كان صورةَ سجّادةٍ لا شعاراً
3. **لاتينيّة الاسم** للنطاق والطباعة (`Ala Jamr`؟)
4. **القائمة النهائيّة والأسعار**
5. **صور الأطباق والصالة** بعد الافتتاح — وتُفحَص حقوقها قبل أن تدخل
6. **حسم معنى «الرسوم الهندية»** — الأرقام أم الزخرفة؟ (الاثنان مُنفَّذان الآن)
